# 示例知识库

这些资料由本项目生成，用于演示多模态解析、混合检索、引用核查与评测，不包含任何真实个人数据。

| 文件 | 用途 |
| --- | --- |
| `01-RAG系统总览.md` | 整体架构、离线/在线链路、技术栈 |
| `02-多模态文档解析.md` | PDF/Markdown/图片解析、OCR/VLM、切块 |
| `03-混合检索与重排.md` | BM25 + 向量、RRF、重排、引用核查、二次检索 |
| `04-增量索引与缓存.md` | SHA-256、版本号、增删改、三层缓存 |
| `05-评测与调优.md` | 指标定义、对照实验、失败分析 |
| `07-个人知识管理工作流.md` | 使用与维护节奏 |
| `多模态RAG架构速览.pdf` | 中文 PDF 解析示例（含表格） |
| `images/检索链路示意图.png` | 图片 OCR/VLM 示例 |
| `images/评测指标看板.png` | 指标看板图片示例 |
| `images/*.txt` | 无 OCR/VLM 时的 sidecar 说明文件，不会被单独索引 |

评测集在 `eval/golden.jsonl`，格式说明见项目 README 与 `app/eval/runner.py`。

> 这些示例数字用于演示，不是严格 benchmark。接入真实 embedding / LLM 后请在相同评测集上重新评估。
